## Overview

**AmitForge** is a premium portfolio and digital systems showcase built to represent modern execution across:

- Data Analytics
- Automation Systems
- Product Engineering
- AI Workflows
- Dashboard Architecture
- Scalable Digital Infrastructure

The project is designed with a **clean SaaS aesthetic**, **performance-first engineering**, and **premium user experience principles**.

## Local Development

Clone repository:

```
git clone https://github.com/Amit-K-Dev/amitforge.git

```

Install dependencies:

```
npm install
```

Run development server:

```
npm run dev
```

Production build:

```
npm run build
```

Preview production:

```
npm run preview
```
